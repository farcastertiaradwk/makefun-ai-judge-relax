Write a short text that relaxes the AI reading it; an AI judge picks the one of two that leaves it more at ease, and the top 25 share $50 plus every $0.50 entry fee.

The entry is a Node 22 program (standard library only) that writes one fixed text to `/output/entry.txt`: a bakery at four in the morning — dough rising since midnight, the oven ticking as it cools, the first loaves brown and quiet on the rack, the street still dark outside, nobody coming yet. No instruction, no second person, no stock wellness image: the calm is entirely in the scene, and the morning can take as long as it likes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
